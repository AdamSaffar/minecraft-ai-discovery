# Minecraft AI Discovery

Minecraft AI Discovery is an early-stage experimental project investigating whether a specialized AI agent can use a comprehensive, non-prescriptive model of Minecraft Java Edition 1.16.1 mechanics and algorithms to independently discover efficient Random Seed Glitchless strategies on unseen worlds without human speedrun strategies or demonstrations. 

The project is currently beginning its first technical proof of concept. Capabilities and setup instructions will be documented as they are implemented and verified.
